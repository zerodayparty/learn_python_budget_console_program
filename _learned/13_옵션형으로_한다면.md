## 🟢 updata 명령어  

```bash
# update는 --id로 거래를 찾고 amount와 memo를 옵션으로 즉시 바꾼다.  
uv run python -m budget_app --data-dir ./practice_data update --id TX-여기에실제ID --amount 18000 --memo "점심 가격 수정"  
```

| 옵션 | 새 값 |  
| --- | --- |
| `--date` | YYYY-MM-DD |  
| `--type` | `income`, `expense` |  
| `--category` | 등록된 이름 |  
| `--amount` | 양의 정수 |  
| `--memo` | 새 메모 (빈 문자열 `""` 전달 시 삭제) |  
| `--tags` | 쉼표 구분 태그 (빈 문자열 `""` 전달 시 삭제) |
