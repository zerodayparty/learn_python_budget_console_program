# 🟩 옵션형으로 할 경우의 명령어 총정리  

CLI(Command Line Interface, 명령줄 인터페이스) 환경에서 각 명령어 뒤에 `--옵션명 값` 형태로 옵션을 붙여 실행하는 방법이다.  

<br><br>

## 🟢 0. 공통 전역 옵션 (--data-dir)  

모든 명령어의 맨 앞(서브 명령어 앞)에 붙여서 데이터가 저장될 폴더를 바꿀 수 있는 옵션이다.  

```bash
# 기본 폴더(data)가 아닌 다른 폴더(test_data)를 데이터 저장소로 지정하여 실행
uv run python -m budget_app --data-dir test_data list
```

| 옵션 | 필수 여부 | 형식 / 예시 | 기본값 | 설명 |  
| --- | --- | --- | --- | --- |  
| `--data-dir` | 선택 | 폴더 경로 (예: `test_data`) | `data` | 데이터 파일(JSONL)들이 저장될 폴더 경로를 지정 |  

<br><br>

## 🟢 1. add 명령어 (대화형 거래 추가)  

현재 가계부 프로그램의 `add` 명령어는 터미널 옵션이 아니라 대화형 프롬프트(질문-답변 방식)로 설계되어 있다.  
따라서 하위 옵션 플래그 없이 실행하며, 터미널이 묻는 질문에 순서대로 값을 입력한다.  

```bash
# 대화형 거래 추가 실행 (실행 후 날짜, 타입, 카테고리, 금액 등을 차례로 질문받음)
uv run python -m budget_app add
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| (옵션 없음) | - | 대화형 입력 | 날짜, 타입, 카테고리, 금액, 메모, 태그를 순서대로 화면에서 직접 입력받음 |  

> [!NOTE]  
> 만약 옵션형으로 직접 거래를 추가하고 싶다면, 현재 프로그램에서는 `add` 대신 일괄 가져오기인 `import` 명령어나 수정용 `update` 명령어를 활용할 수 있다.  

<br><br>

## 🟢 2. list 명령어 (거래 목록 최신순 조회)  

저장된 거래를 가장 최근에 입력된 순서(역순)부터 화면에 출력하는 명령어다.  

```bash
# 기본값인 최근 10건의 거래 목록 출력
uv run python -m budget_app list

# 최근 거래를 5건만 지정해서 출력
uv run python -m budget_app list --limit 5
```

| 옵션 | 필수 여부 | 형식 / 예시 | 기본값 | 설명 |  
| --- | --- | --- | --- | --- |  
| `--limit` | 선택 | 1 이상의 정수 (예: `5`, `20`) | `10` | 화면에 출력할 최근 거래의 최대 개수 |  

<br><br>

## 🟢 3. search 명령어 (조건별 거래 검색)  

날짜 범위, 카테고리, 수입/지출 타입, 메모 단어, 태그 등의 옵션을 조합하여 원하는 거래만 골라내는 명령어다. 여러 옵션을 함께 주면 모든 조건을 동시에 만족하는 거래만 찾는다.  

```bash
# 식비 카테고리이면서 지출(expense)인 거래 검색
uv run python -m budget_app search --category 식비 --type expense

# 특정 날짜 범위(2026-03-01 ~ 2026-03-31) 내의 거래 검색
uv run python -m budget_app search --from 2026-03-01 --to 2026-03-31

# 메모에 '점심'이라는 단어가 들어가고 '외식' 태그가 달린 거래 검색
uv run python -m budget_app search --q 점심 --tag 외식
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--from` | 선택 | `YYYY-MM-DD` (예: `2026-03-01`) | 검색 시작 날짜 |  
| `--to` | 선택 | `YYYY-MM-DD` (예: `2026-03-31`) | 검색 종료 날짜 |  
| `--category` | 선택 | 문자열 (예: `식비`, `교통비`) | 찾고자 하는 카테고리 이름 |  
| `--type` | 선택 | `income`, `expense` | 거래 종류 (수입 또는 지출) |  
| `--q` | 선택 | 검색어 문자열 (예: `점심`) | 메모에 포함되어 있는 글자 (부분 일치) |  
| `--tag` | 선택 | 단일 태그 문자열 (예: `외식`) | 거래에 등록된 태그 중 일치하는 태그 |  

<br><br>

## 🟢 4. summary 명령어 (월별 수입·지출 요약 통계)  

특정 월의 총 수입, 총 지출, 순이익, 설정된 예산 대비 지출율, 그리고 가장 많이 지출한 카테고리 TOP 순위를 계산해 보여주는 명령어다.  

```bash
# 2026년 3월 통계 확인 (기본 상위 5개 지출 카테고리 표시)
uv run python -m budget_app summary --month 2026-03

# 2026년 3월 통계 확인 및 상위 지출 카테고리를 3개만 표시
uv run python -m budget_app summary --month 2026-03 --top 3
```

| 옵션 | 필수 여부 | 형식 / 예시 | 기본값 | 설명 |  
| --- | --- | --- | --- | --- |  
| `--month` | 필수 | `YYYY-MM` (예: `2026-03`) | 없음 | 통계를 낼 대상 연도와 월 |  
| `--top` | 선택 | 1 이상의 정수 (예: `3`, `10`) | `5` | 지출이 큰 상위 카테고리 출력 개수 |  

<br><br>

## 🟢 5. budget 명령어 (월별 예산 설정 및 조회)  

한 달 동안 사용할 목표 지출 예산을 저장하거나, 저장된 예산 금액을 조회하는 명령어다. `set`과 `get` 두 가지 하위 작업을 지원한다.  

### 🟡 budget set (예산 저장)  

```bash
# 2026년 3월 예산을 500,000원으로 설정
uv run python -m budget_app budget set --month 2026-03 --amount 500000
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--month` | 필수 | `YYYY-MM` (예: `2026-03`) | 예산을 설정할 연도와 월 |  
| `--amount` | 필수 | 1 이상의 정수 (예: `500000`) | 한 달 목표 예산 금액 (원 단위) |  

### 🟡 budget get (예산 조회)  

```bash
# 2026년 3월에 설정된 예산 금액 확인
uv run python -m budget_app budget get --month 2026-03
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--month` | 필수 | `YYYY-MM` (예: `2026-03`) | 예산을 확인할 연도와 월 |  

<br><br>

## 🟢 6. category 명령어 (카테고리 관리)  

가계부에서 사용할 카테고리 목록을 관리하는 명령어다. `add`, `list`, `exists`, `remove` 네 가지 하위 작업을 지원한다.  

### 🟡 category add (카테고리 추가)  

```bash
# 문화생활 카테고리를 옵션으로 즉시 추가
uv run python -m budget_app category add --name 문화생활
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--name` | 선택 | 문자열 (예: `문화생활`) | 추가할 카테고리 이름 (생략 시 대화형으로 물어봄) |  

### 🟡 category list (카테고리 목록 보기)  

```bash
# 등록된 모든 카테고리 목록을 가나다순으로 확인
uv run python -m budget_app category list
```

| 옵션 | 필수 여부 | 설명 |  
| --- | --- | --- |  
| (옵션 없음) | - | 등록된 카테고리를 한 줄에 하나씩 글머리기호(`-`)로 출력 |  

### 🟡 category exists (특정 카테고리 존재 여부 확인)  

```bash
# 식비 카테고리가 등록되어 있는지 확인
uv run python -m budget_app category exists --name 식비
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--name` | 선택 | 문자열 (예: `식비`) | 확인할 카테고리 이름 (생략 시 대화형으로 물어봄) |  

### 🟡 category remove (카테고리 삭제)  

```bash
# 문화생활 카테고리를 삭제 (단, 기존 거래에 사용된 적이 없어야 삭제 가능)
uv run python -m budget_app category remove --name 문화생활
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--name` | 선택 | 문자열 (예: `문화생활`) | 삭제할 카테고리 이름 (생략 시 대화형으로 물어봄) |  

<br><br>

## 🟢 7. update 명령어 (거래 내용 수정)  

기존에 등록된 거래 ID(Identifier, 식별자)를 지정하여 원하는 필드만 즉시 새로운 값으로 변경하는 명령어다.  

```bash
# 거래 ID가 TX-20260309-123456인 거래의 금액과 메모를 수정
uv run python -m budget_app update --id TX-20260309-123456 --amount 18000 --memo "점심 가격 수정"

# 날짜와 카테고리를 동시에 변경
uv run python -m budget_app update --id TX-20260309-123456 --date 2026-03-08 --category 식비

# 기존 메모를 빈 문자열("")로 주어 완전히 삭제
uv run python -m budget_app update --id TX-20260309-123456 --memo ""
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--id` | 필수 (옵션 사용 시) | 고유 ID (예: `TX-20260309-123456`) | 수정할 대상 거래의 식별 번호 (생략 시 대화형으로 진행) |  
| `--date` | 선택 | `YYYY-MM-DD` (예: `2026-03-08`) | 변경할 새 날짜 |  
| `--type` | 선택 | `income`, `expense` | 변경할 새 거래 타입 |  
| `--category` | 선택 | 등록된 카테고리명 (예: `식비`) | 변경할 새 카테고리 |  
| `--amount` | 선택 | 1 이상의 정수 (예: `18000`) | 변경할 새 금액 |  
| `--memo` | 선택 | 문자열 (빈 문자열 `""` 입력 시 삭제) | 변경할 새 메모 |  
| `--tags` | 선택 | 쉼표 구분 문자열 (빈 문자열 `""` 입력 시 삭제) | 변경할 새 태그 목록 (예: `외식,친구`) |  

<br><br>

## 🟢 8. delete 명령어 (거래 삭제)  

더 이상 필요 없는 거래를 거래 ID를 통해 영구히 삭제하는 명령어다.  

```bash
# 지정한 거래 ID를 찾아 삭제
uv run python -m budget_app delete --id TX-20260309-123456
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--id` | 필수 | 고유 ID (예: `TX-20260309-123456`) | 삭제할 대상 거래의 식별 번호 |  

<br><br>

## 🟢 9. import 명령어 (CSV 파일로부터 거래 가져오기)  

외부 CSV(Comma-Separated Values, 쉼표로 구분한 파일) 파일에 적힌 여러 건의 거래를 한 번에 읽어 가계부에 일괄 저장하는 명령어다.  

```bash
# data 폴더 안의 transactions_backup.csv 파일로부터 거래 데이터를 읽어오기
uv run python -m budget_app import --from data/transactions_backup.csv
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--from` | 필수 | 파일 경로 (예: `data/sample.csv`) | 가져올 UTF-8 형식의 CSV 파일 경로 |  

<br><br>

## 🟢 10. export 명령어 (CSV 파일로 거래 내보내기)  

가계부에 저장된 거래들을 CSV 파일로 추출하여 백업하거나 엑셀 등에서 열어볼 수 있도록 저장하는 명령어다.  

```bash
# 전체 거래를 data/all_export.csv 파일로 내보내기
uv run python -m budget_app export --out data/all_export.csv

# 2026년 3월 거래만 골라서 CSV 파일로 내보내기
uv run python -m budget_app export --out data/export_2026_03.csv --month 2026-03

# 2026년 3월 1일부터 3월 15일까지의 거래만 날짜 범위로 내보내기
uv run python -m budget_app export --out data/export_period.csv --from 2026-03-01 --to 2026-03-15
```

| 옵션 | 필수 여부 | 형식 / 예시 | 설명 |  
| --- | --- | --- | --- |  
| `--out` | 필수 | 저장할 파일 경로 (예: `data/out.csv`) | 결과를 저장할 CSV 파일의 경로 |  
| `--month` | 선택 | `YYYY-MM` (예: `2026-03`) | 특정 월의 거래만 골라서 내보낼 때 사용 |  
| `--from` | 선택 | `YYYY-MM-DD` (예: `2026-03-01`) | 내보낼 거래의 시작 날짜 (날짜 범위 필터) |  
| `--to` | 선택 | `YYYY-MM-DD` (예: `2026-03-15`) | 내보낼 거래의 종료 날짜 (날짜 범위 필터) |  

<br><br>

## 🟢 11. interactive 명령어 (대화형 메뉴 모드 진입)  

명령어 옵션을 치지 않고 터미널에서 번호(1~9)를 골라 가며 가계부를 조작하는 대화형 콘솔 모드로 진입하는 명령어다.  

```bash
# 대화형 콘솔 모드로 직접 진입
uv run python -m budget_app interactive

# 명령어와 옵션을 아무것도 입력하지 않아도 대화형 모드로 자동 진입
uv run python -m budget_app
```

| 옵션 | 필수 여부 | 설명 |  
| --- | --- | --- |  
| (옵션 없음) | - | 번호 선택 기반의 풀 스크린 대화형 콘솔 메뉴를 실행 |

## 🟢 용어 풀네임 및 개념 정리  

- CLI  
    - 풀네임: Command Line Interface  
    - 해설: 키보드로 명령어를 직접 타이핑하여 컴퓨터 프로그램을 조작하는 방식  
- CSV  
    - 풀네임: Comma-Separated Values  
    - 해설: 각 항목 데이터를 쉼표(`,`)로 구분하여 표 형태로 저장한 텍스트 파일  
- JSONL  
    - 풀네임: JavaScript Object Notation Lines  
    - 해설: 데이터 한 건을 한 줄의 JSON 규격으로 저장하여 줄바꿈으로 나열한 파일 형식  
- ID  
    - 풀네임: Identifier  
    - 해설: 거래 한 건 한 건을 고유하게 식별하기 위한 고유 번호 또는 문자열  
- UV  
    - 풀네임: Ultra Fast Python Package and Project Manager  
    - 해설: 파이썬 가상환경 생성 및 패키지 실행을 매우 빠르게 처리해 주는 도구  
- ARG  
    - 풀네임: Argument  
    - 해설: 명령어나 프로그램 뒤에 덧붙여서 전달해 주는 값이나 파라미터
