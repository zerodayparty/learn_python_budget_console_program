# 🟩 파이썬 b"" (바이트 리터럴) 의미와 동작 원리

## 🟢 주요 영단어 풀네임 정리

- 용어 풀네임 목록
    - b = Bytes (바이트 / 8개의 비트로 이루어진 컴퓨터 기본 저장 단위)
    - str = String (문자열 / 사람이 눈으로 읽을 수 있는 글자들의 나열)
    - bytes = Bytes (바이트 열 / 컴퓨터가 처리하는 0부터 255까지 숫자들의 묶음)
    - rb = Read Binary (이진 읽기 모드 / 파일을 글자로 번역하지 않고 0과 1 그대로 읽기)
    - literal = Literal (문자 그대로의 값 / 코드에 직접 적어 넣은 고정된 값)
    - encode = En-code (암호화하다, 부호화하다 / 사람이 읽는 글자를 컴퓨터 바이트로 바꾸다)
    - decode = De-code (해독하다, 복호화하다 / 컴퓨터 바이트를 사람이 읽는 글자로 바꾸다)
    - TypeError = Type Error (자료형 오류 / 서로 맞지 않는 다른 종류의 데이터를 계산하려 할 때 발생)

<br><br>

## 🟢 b"" 의 정체 (팩트 정의)

### 🟡 1. b의 의미
- 문자열 따옴표 앞에 붙은 영문자 `b`는 **Bytes(바이트)**의 앞 글자임.
- 따옴표 안에 적힌 내용이 '사람이 읽는 일반 글자(`str`)'가 아니라 **'컴퓨터 기계가 다루는 날것의 2진수 바이트 데이터(`bytes`)'**임을 파이썬에 선언하는 표시임.

<br><br>

### 🟡 2. b"" 의 의미
- 따옴표 안이 비어 있는 `b""`는 **"크기가 0인 빈 바이트 덩어리(빈 바이트 객체)"**를 의미함.
- 일반 글자에서 `""`이 글자 수가 0개인 빈 문자열인 것처럼, `b""`는 바이트 크기가 0인 빈 바이트 데이터임.

<br><br>

## 🟢 일반 문자열("") vs 바이트 문자열(b"") 완벽 비교

컴퓨터 세상에는 두 종류의 글자 표현 방식이 존재함.

| 비교 항목 | 일반 문자열 (`""`) | 바이트 문자열 (`b""`) |
| :--- | :--- | :--- |
| 파이썬 자료형 | `str` (String) | `bytes` (Bytes) |
| 대상 | **사람** (사람이 읽고 쓰는 언어) | **컴퓨터 기계** (디스크, 전선, 네트워크) |
| 다루는 단위 | 글자 단위 ('A', '가', '😊') | byte 단위 (0~255 사이의 2진수 숫자) |
| 한글 저장 시 크기 | `'가'` $\rightarrow$ 1글자 | `b'\xea\xb0\x80'` $\rightarrow$ 3 byte |
| 파일 열기 모드 | `open("r")` (텍스트 읽기) | `open("rb")` (이진 읽기) |

<br><br>

## 🟢 왜 repositories.py에서는 "" 대신 b""를 썼는가?

### 🟡 1. open("rb") 로 파일을 열었기 때문
- `repositories.py`의 62번째 줄을 보면 파일을 다음과 같이 열었음:
    - `with path.open("rb") as data_file:`
- `"rb"`는 **Read Binary(이진 읽기)**의 약자임.
- 컴퓨터 하드디스크에서 번역(UTF-8 디코딩)을 거치지 않고, 0과 1의 숫자 묶음인 **`bytes` 형태로 원시 데이터를 그대로 퍼 올림**.
- 따라서 `data_file.read()`가 읽어오는 결과물은 무조건 `bytes` 자료형임.

<br><br>

### 🟡 2. 파이썬의 엄격한 법칙: 종족이 다르면 더할 수 없다!
- 파이썬은 일반 글자(`str`)와 바이트(`bytes`)를 섞어서 더하는 것을 엄격히 금지함.
- 섞어서 더하려고 하면 즉시 프로그램이 멈추고 `TypeError` 에러가 발생함.

```python
# 일반 문자열과 바이트를 준비한다.
글자 = "Banana"
바이트 = b"Banana"

# ❌ 오류 발생: 서로 다른 종족끼리는 더할 수 없다!
# TypeError: can't concat str to bytes
잘못된더하기 = 바이트 + 글자

# ⭕ 정상 동작: 바이트끼리는 얼마든지 더할 수 있다!
바이트더하기 = b"Bana" + b"na"  # 결과: b"Banana"
```

<br><br>

### 🟡 3. remaining 변수의 초기값 역할
- `repositories.py` 65번째 줄:
    - `remaining = b""`
- `remaining`은 나중에 72번째 줄에서 새로 읽어온 블록과 합쳐져야 함:
    - `block = data_file.read(read_size) + remaining`
- `data_file.read()`가 `bytes`를 반환하므로, 뒤에 붙일 `remaining`도 **반드시 `bytes` 자료형**이어야 에러 없이 더하기가 성립함.
- 첫 번째 반복에서는 아직 잘린 조각이 없으므로, **"아무것도 없는 빈 바이트(`b""`)"**를 넣어둔 것임.
- 숫자 계산에서 `합계 = 0`으로 시작하는 것처럼, 바이트 계산에서는 `remaining = b""`로 시작하는 원리와 100% 동일함.

<br><br>

## 🟢 코드 실험 및 동작 검증

```python
# 1. 빈 바이트 객체를 생성한다.
빈바이트 = b""

# 2. 빈 바이트의 길이를 측정하면 0이 나온다.
print(len(빈바이트))  # 출력: 0

# 3. 빈 바이트에 다른 바이트를 더하면 원래 내용이 그대로 유지된다 (0을 더하는 것과 같음).
결과 = b"Cherry" + 빈바이트
print(결과)  # 출력: b'Cherry'

# 4. 바이트를 사람이 읽는 한글/영어로 바꾸려면 decode()를 실행한다.
문자열 = 결과.decode("utf-8")
print(문자열)  # 출력: Cherry
```

## 🟢 타인에게 1분 만에 설명하는 요약 공식

- **`b`의 정체**: 사람용 글자(`str`)가 아니라 컴퓨터용 2진수 덩어리(`bytes`)임을 파이썬에 알리는 표식임.
- **`b""`의 뜻**: 내용물이 하나도 없는 0 byte짜리 빈 바이트 주머니임.
- **왜 쓰는가?**: 파일을 `rb`(이진 읽기)로 읽었기 때문에 읽어온 데이터가 전부 `bytes`임. 파이썬은 `bytes`끼리만 덧셈이 가능하므로 초기 주머니도 일반 빈 글자(`""`)가 아닌 빈 바이트(`b""`)로 준비해야 에러가 나지 않음.
